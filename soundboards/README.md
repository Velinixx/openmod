# Soundboards

Soundboard clips and their trigger configs live here.

Not implemented yet (see README roadmap) — this directory reserves the
structure so soundboard PRs have a home:

```
soundboards/
├── default/
│   ├── board.json      # clip list, hotkeys, volume
│   └── clips/
│       ├── airhorn.wav
│       └── bruh.wav
```

Clip configs will be JSON like presets — forkable, PR-able, no account needed.
